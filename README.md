## 🧠 AI 生成代码关键逻辑解释

> 用自己的话解释至少 2 处 AI 生成代码的关键逻辑

### 1. 贪吃蛇的移动原理

贪吃蛇的移动不是真的"移动"每一格，而是用了一个巧妙的方法：
- **加头去尾**：每一帧在蛇头前进方向新增一个格子（unshift），同时去掉蛇尾巴（pop）
- **吃食物时只加不去**：如果蛇头碰到食物，就只加头不去尾，蛇身就变长了
- 用数组 `snake` 来表示整条蛇，每个元素存 x,y 坐标，`snake[0]` 是蛇头

### 2. AI 避障的判断逻辑

AI 不是随便走的，它每一步都会做安全检查：
- 第一步：找出所有"安全方向"——不会撞墙、不会撞到自己身体的方向
- 第二步：从安全方向里，选离食物最近的那个（贪心策略）
- 第三步：额外加一步"预判"——往前走一步之后，下一步还有没有路可走，避免走进死胡同
- 这样 AI 既能朝食物前进，又不会轻易把自己困死

## 🔧 通用素养

### Git 操作

- **仓库 commit 次数**：不少于 3 次（分阶段提交）
- **什么是分支（Branch）**：分支就是一条独立的开发线，可以在不影响主代码的情况下开发新功能，开发完了再合并回去。就像写作文先打草稿，改好了再抄到正本上。
- **什么是合并（Merge）**：合并就是把两个分支的代码合到一起。比如你在"新功能分支"写完了代码，确认没问题后，就把它合并回"主分支"，让所有人都能用到新功能。

### 命令行常用命令

- `cd`：切换目录（change directory），比如 `cd Documents` 就是进入 Documents 文件夹
- `ls`：列出当前目录下的文件和文件夹
- `mkdir`：创建新文件夹（make directory），比如 `mkdir project`
- `git init`：初始化一个 Git 仓库
- `git add`：把文件添加到暂存区
- `git commit`：提交代码到仓库，要写提交信息说明改了什么
- `git push`：把本地代码推送到 GitHub 远程仓库
- `git log`：查看提交历史记录
